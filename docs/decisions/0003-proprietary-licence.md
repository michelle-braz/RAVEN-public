# 0003: Proprietary licence for original code

> Classification: Decision Record. Status: accepted, pending counsel confirmation.

**Context.** RAVEN is to be sold. The repository was MIT-licensed and public; the owner is the sole copyright holder.

**Decision.** Replace the LICENSE with an all-rights-reserved notice from commit after `0f66b49`, document the MIT
history, keep third-party licences intact and inventoried, mark the package non-uploadable.

**Consequences.** Earlier copies stay MIT. Public visibility of the repository is a separate owner decision. A
customer agreement is required to grant use rights ([legal](../legal/README.md)).
